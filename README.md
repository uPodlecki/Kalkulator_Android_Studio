# Kalkulator_Android_Studio
# Kalkulator Jetpack Compose 🧮  Prosta, intuicyjna i responsywna aplikacja kalkulatora stworzona na system Android. Projekt służy jako praktyczne wprowadzenie do tworzenia nowoczesnych interfejsów użytkownika przy użyciu Jetpack Compose oraz zarządzania stanem (State) w Kotlinie.
## 🚀 Funkcjonalności
* **Podstawowe operacje matematyczne:** Dodawanie, odejmowanie, mnożenie i dzielenie.
* **Nowoczesny interfejs:** Czysty i czytelny wygląd zbudowany w 100% za pomocą Jetpack Compose.
* **Zarządzanie stanem:** Wykorzystanie `MutableState` do płynnego i natychmiastowego odświeżania wyników na ekranie.
* **Responsywność:** Zastosowanie modyfikatorów układu (Row, Column, Box) zapewniających poprawne wyświetlanie na różnych rozmiarach ekranów.

## 🛠️ Technologie
* **Język:** Kotlin
* **UI:** Jetpack Compose
* **Środowisko:** Android Studio
